# 🪙 뀨뀨 미션 수행 대작전!

아이의 하루 미션을 체크하고 코인으로 모아, 현금처럼 쓸 수 있는 우리 집 전용 웹앱입니다.
매일 7개씩 **초등·중등 영단어 2,000개**도 함께 외워요.
민트 · 연보라 색감의 아기자기한 화면과 마스코트 캐릭터 **뀨뀨**가 함께해요.

- **앱 열기**: https://hbreezy620-cloud.github.io/kid-mission-coin/
- 안드로이드 크롬에서 열고 **⋮ → 홈 화면에 추가** 하면 일반 앱처럼 아이콘으로 실행됩니다.

## 규칙

| 항목 | 내용 |
| --- | --- |
| 하루 미션 | 그날 미션을 **모두** 체크하면 **코인 +1** (하루 한 번) |
| 오늘의 영단어 | 매일 **7단어** 카드로 익히고, **한글 뜻을 보고 스펠링을 적는 퀴즈 7문제를 모두 맞히면 코인 +1** (하루 한 번) |
| 주간 개근 | 월~일 **7일 모두** (각 날마다 미션이 있고 모두 완료) **+3코인** (주당 한 번) |
| 코인 가치 | 1코인 = **100원** |
| 현금 사용 | **30코인(3,000원) 이상**부터 사용 가능, 금액은 직접 선택 |

## 화면

- **오늘** — 오늘의 미션 체크, 이번 주 스탬프, 코인 잔액
- **영단어** — **초등 필수 800 + 중등 필수 1,200 = 2,000개**를 하루 **7개씩 286일**에 걸쳐.
  앞 800개(1~114일차)는 **초등 필수**, 그 뒤 1,200개는 **중등 필수** 단계로 이어지고 화면 위 뱃지로 지금 단계를 알려 줍니다.
  카드를 **누르면 영어 스펠링 ↔ 한글 뜻**이 번갈아 나오고, 🔊 버튼으로 발음을 듣습니다.
  이어서 **한글 뜻 → 스펠링 퀴즈 7문제**: 뜻만 보고 직접 스펠링을 적고, 필요하면 🔊 발음 듣기로 확인합니다.
  틀리면 흔들림과 함께 다시 시도하고, **두 번 틀리면 글자 수·첫 글자 힌트**가 나옵니다.
  다 맞히면 코인 +1, 지난 날의 단어는 **복습** 목록에서 다시 볼 수 있어요.
- **이번 주** — 요일별 기록과 개근 진행률, 요일별 미션 목록·수정
- **코인** — 잔액·원화 환산, 현금 사용(보호자 확인), 코인 내역
- **미션 정하기** — 이번 주/다음 주, **요일(월~일)을 골라 그날의 체크리스트를 따로** 추가·삭제.
  같은 미션이 매일 반복되면 `📥 지난 주 같은 요일 불러오기` · `📋 모든 요일에 똑같이` 로 빠르게 복사

## 저장

모든 기록은 그 기기의 브라우저 `localStorage`(키 `kidMissionCoin.v1`)에만 저장됩니다. 이전 버전 `미션 코인`에서 쓰던 기록도 그대로 이어집니다. 요일별 미션 기록(`weeks.몇주.dayMissions`)이 없던 옛 데이터는 주 공통 미션 목록을 모든 요일이 그대로 쓰고, 특정 요일을 고치기 시작할 때 그날만 따로 분리해 저장합니다. 영단어 학습 기록은 `words`(시작일 · 날짜별 7문제 진행)에 따로 쌓이고, 코인은 기존 `ledger`에 `type: "words"`로 함께 기록되어 잔액·내역에 그대로 합산됩니다.
하루 5단어이던 옛 버전의 날짜별 영단어 진도는 단어 순서가 달라져 `words.legacy5`에 그대로 보관만 하고 새로 시작합니다(코인 잔액·내역은 손대지 않습니다). 설정에서 JSON으로 내보내기·불러오기가 가능합니다.

## 단어 데이터

`index.html` 안의 `WORDS_2000` 배열 2,000개 항목 — 각 `[영단어, 한글 뜻, 단계(0 초등 / 1 중등), (허용 표기)]`.

- **초등 필수 800개**: 2015 교육부 고시 초등학교 기본 어휘 800개를 바탕으로 정리한 기존 목록 그대로.
- **중등 필수 1,200개**: **2022 개정 교육부 지정 중등 기본어휘 1,200개**(전반 600 + 후반 600)를 기본으로 하고,
  그중 초등 800개와 겹치는 142개를 빼고, **중학 2~3학년 필수 영단어 900** 목록에서 교육부 기본어휘에 있는 단어 142개를 보충해 총 1,200개를 맞췄습니다.
- 중복 단어 0, 한글 뜻 누락 0, 뜻이 겹쳐 답이 헷갈리는 단어 0(같은 뜻은 `눈 (얼굴의 눈)`처럼 구분)을 스크립트로 전수 검사했습니다.
- 하루 7개씩 286일(마지막 286일차는 5개)이면 2,000개를 모두 만나고, 287일째부터는 1일차 복습 라운드입니다.
