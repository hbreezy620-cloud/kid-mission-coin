# 🪙 뀨뀨 미션 수행 대작전!

아이의 하루 미션을 체크하고 코인으로 모아, 현금처럼 쓸 수 있는 우리 집 전용 웹앱입니다.
민트 · 연보라 색감의 아기자기한 화면과 마스코트 캐릭터 **뀨뀨**가 함께해요.

- **앱 열기**: https://hbreezy620-cloud.github.io/kid-mission-coin/
- 안드로이드 크롬에서 열고 **⋮ → 홈 화면에 추가** 하면 일반 앱처럼 아이콘으로 실행됩니다.

## 규칙

| 항목 | 내용 |
| --- | --- |
| 하루 미션 | 그날 미션을 **모두** 체크하면 **코인 +1** (하루 한 번) |
| 오늘의 영단어 | 매일 **5단어** 카드로 익히고 빈칸 퀴즈 **5문제를 모두 맞히면 코인 +1** (하루 한 번) |
| 주간 개근 | 월~일 **7일 모두** (각 날마다 미션이 있고 모두 완료) **+3코인** (주당 한 번) |
| 코인 가치 | 1코인 = **100원** |
| 현금 사용 | **30코인(3,000원) 이상**부터 사용 가능, 금액은 직접 선택 |

## 화면

- **오늘** — 오늘의 미션 체크, 이번 주 스탬프, 코인 잔액
- **영단어** — 교육부 초등 필수 영단어 **800개**를 하루 5개씩(160일치).
  카드를 **누르면 영어 스펠링 ↔ 한글 뜻**이 번갈아 나오고, 🔊 버튼으로 발음을 듣습니다.
  이어서 **빈칸 채우기 5문제**(예문 속 `_____`에 직접 입력, 동사 과거형·복수형 등 **문법 힌트** 표시).
  다 맞히면 코인 +1, 지난 날의 단어는 **복습** 목록에서 다시 볼 수 있어요.
- **이번 주** — 요일별 기록과 개근 진행률, 요일별 미션 목록·수정
- **코인** — 잔액·원화 환산, 현금 사용(보호자 확인), 코인 내역
- **미션 정하기** — 이번 주/다음 주, **요일(월~일)을 골라 그날의 체크리스트를 따로** 추가·삭제.
  같은 미션이 매일 반복되면 `📥 지난 주 같은 요일 불러오기` · `📋 모든 요일에 똑같이` 로 빠르게 복사

## 저장

모든 기록은 그 기기의 브라우저 `localStorage`(키 `kidMissionCoin.v1`)에만 저장됩니다. 이전 버전 `미션 코인`에서 쓰던 기록도 그대로 이어집니다. 요일별 미션 기록(`weeks.몇주.dayMissions`)이 없던 옛 데이터는 주 공통 미션 목록을 모든 요일이 그대로 쓰고, 특정 요일을 고치기 시작할 때 그날만 따로 분리해 저장합니다. 영단어 학습 기록은 `words`(시작일 · 날짜별 5문제 진행)에 따로 쌓이고, 코인은 기존 `ledger`에 `type: "words"`로 함께 기록되어 잔액·내역에 그대로 합산됩니다. 설정에서 JSON으로 내보내기·불러오기가 가능합니다.

## 단어 데이터

`index.html` 안의 `WORDS_800` 배열 800개 항목 — 각 `[영단어, 뜻, 예문(빈칸 포함), 정답, 문법 힌트, 예문 해석]`.
2015 교육부 고시 초등학교 기본 어휘 800개를 바탕으로 구성했고, 하루 5개씩 160일이면 모두 만납니다.

## 구성

- `index.html` — 앱 전체 (단일 파일, 외부 라이브러리 없음 · 귀여운 글씨체는 Google Fonts `Jua`/`Gowun Dodum`, 오프라인에선 기본 글씨체로 표시)
- `manifest.json`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — 홈 화면 추가용
